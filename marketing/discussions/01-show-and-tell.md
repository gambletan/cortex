# 🧠 Try Cortex in your browser — 124KB WASM, zero install

> Category: **Show and tell**

Cortex now runs **entirely in your browser** — no install, no server, no account. The whole memory engine compiles to a **124 KB WASM** bundle and executes 100% client-side.

👉 **Live demo: https://gambletan.github.io/cortex/**

Try the quick-demo buttons:
- *"I live in Shanghai and work at Google"* → watch it auto-extract structured facts
- *"I prefer dark mode and use neovim"* → preferences captured
- Then search across what you stored — all locally, nothing leaves the tab.

This is the same Rust core that powers the native binary (3.8 MB) and the MCP server. If you build something with it, drop a screenshot here — would love to see it. ⭐
