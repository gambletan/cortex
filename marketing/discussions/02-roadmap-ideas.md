# Roadmap v2.2 — what should we build next?

> Category: **Ideas**

Cortex v2.1 shipped the WASM build (124 KB, in-browser demo). Now planning **v2.2** and would love input from people actually wiring Cortex into agents.

**On the table for v2.2:**
- 📱 Mobile targets (iOS / Android bindings)
- 🖼️ Multi-modal memory (images, not just text)

**Other candidates I keep going back and forth on:**
- A first-class CLI (`cortex add "..."`, `cortex search "..."`) instead of only HTTP/MCP
- More language NLP beyond EN + CN (JA? KO? ES?)
- A LangChain / LlamaIndex memory adapter
- Encrypted multi-user namespaces over shared cloud sync

**What would actually move the needle for your use case?** 👍 the ideas you want, or drop a new one. If you're integrating Cortex with a specific agent framework (CrewAI, AutoGen, LangGraph, custom), tell me what's missing.
